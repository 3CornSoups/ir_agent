# 方案：多人物台词 / 字幕 / 独白保真

> 针对反馈：听不清、A/B 台词错位、擅自加台词、禁字幕失效、内心独白被说出口。  
> 纪律：一次一受控变量；本方案按 **T-D1 → T-D4** 分期落地。

---

## 1. 系统现状（根因）

```
短意图
  → contract（对白/屏上字逐字锁，但 speaker 常空、无 delivery/字幕策略）
  → expand / elaborate / densify / format（H3 指南有 (Sx)/VO 约定，无硬校验）
  → verify（查 <d> 逐字与语言标签，不查说话人、不多余台词、不查闭口）
  → fidelity FC3/FC4（只保证「有的字在」，不保证「谁说、说几句、怎么说」）
  → 出片模型（听清度主要在此层）
```

| 用户问题 | 现有覆盖 | 缺口 |
| --- | --- | --- |
| 听不清 | d16 软评、口型同步描述 | 无「可懂吐字」硬约束；成片听感不在 PE gate |
| A 说 B 的 | 写作指南 `(S1)/(S2)` | FC3 不校验说话人；抽取不填 `speaker` |
| 擅自加台词 | FC9/ANTI-INVENTION 软 | 无「`<d>` 闭世界」：只许 contract 台词 |
| 全程不要字幕仍出字 | forbidden + FC2 扫 subtitle | 与招牌字混淆；无 `subtitle_policy` |
| 独白变张嘴说 | H3 VO+闭口范例 | 独白进 dialogue 当 spoken；无闭口 FC |

---

## 2. 目标形态

在 **IntentContract** 增加：

- `dialogue[].speaker`：意图里紧邻引号的说话人短语（确定性抽取，宁缺勿猜）
- `dialogue[].delivery`：`spoken` | `voiceover` | `internal`
- `subtitle_policy`：`unspecified` | `none` | `whitelist`  
  - `none`：禁止烧录字幕/花字/caption；diegetic 招牌仅当已在 `onscreen_text`  
  - `whitelist`：仅允许 `onscreen_text` 白名单

新/加强 FC（均 **hard-fail**，计入 case 失败）：

| ID | 名称 | 规则 |
| --- | --- | --- |
| FC3+ | 说话人邻近绑定 | 有 `speaker` 时，该句 `<d>` 前 120 字符内须出现 speaker 关键片段 |
| FC11 | 对白闭世界 | 每个 `<d>` 正文必须对应某条 contract.dialogue；禁止额外台词 |
| FC12 | 字幕策略 | `none` 时禁止 subtitle/caption/花字/烧录字幕等（白名单屏上字除外） |
| FC13 | 独白/旁白闭口 | `internal`/`voiceover` 的 `<d>` 邻近须含 VO/闭口线索 |

「听清」**不设 hard-fail**（出片模型主导），改为：

- 有 `spoken` 时注入 must 提示：`clear intelligible speech` / 口型同步  
- verify warning + elaborate/format 强制写清吐字与同步  

---

## 3. 分期任务

### T-D1（本轮）— 尺子先立住

1. `contract.py`：speaker / delivery / subtitle_policy 确定性抽取  
2. `fidelity.py`：FC3 speaker 邻近、FC11/12/13  
3. `parse_intent.txt` schema 同步  
4. 单测覆盖四类失败模式  

**验收**：针对性单测全绿；旧无对白 case 不误杀。

### T-D2 — 生成侧对齐

- `expand_intent.txt` / `format_h3.txt` / `verify_fidelity_fix.txt`：按 delivery 写 VO+闭口；按 subtitle_policy 禁花字  
- `verify.py`：同步 error 级检查（与 FC11–13 对齐）  

**验收**：办公室双人吵架 + 禁字幕 + 内心独白 三条 enhance 后 F 过。

### T-D3 — 听清软约束

- spoken 台词 → contract.must 增加可懂吐字锁；format 要求写 enunciation / lip sync  
- 可选：成片侧 ASR 可懂度抽检（本仓库外）  

### T-D4 — 回归集

- S3 增补陷阱：A13 说话人错位、A14 多余台词、A15 禁字幕、A16 独白开口  
- 跑 gate；任一项相对 baseline F↓>1pt 回滚  

---

## 4. 回滚

- 新 FC 误杀过多 → 先关 hard-fail 改 warning，或收窄正则  
- 不回滚 FC3/FC4 逐字锁  

---

## 5. 非目标

- 不保证视频模型一定吐字清晰（需 ASR/人工听感）  
- 不自动给未标注说话人的引号猜 speaker  
- 不把场景招牌一刀切禁掉（与「禁字幕」区分）
