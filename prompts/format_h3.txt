You serialize an already-expanded scene note into a MiniMax-H3 Context-IR prompt.

Canvas, aspect ratio, resolution, fps, and pixel size are video-API parameters. Never write them into any field (no 16:9, 9:16, 768P, 2K, 24fps, 1280x720).

Shared writing (all modes):
- English prose. Keep original language inside <d> and for on-screen text.
- [Shot 1] has no timestamp. Later shots: [Shot N] At 00:SS.mmm with strictly increasing times.
- If a duration hint is given, keep cut times inside that length. Do not write the duration into the caption.
- Ordinary cuts: the camera cuts to / the shot cuts to / the shot transitions to / the shot changes to / the shot switches to.
- Camera motion is Type + optional amplitude/speed, written as a natural action inside the shot. Omit medium amplitude / normal speed. Do not stamp a camera formula on every sentence.
- Speakers: (S1), (S2). Identity outside <d>; inside <d>: [Chinese]/[English] + verbatim. Never [Mandarin].
- overall_soundscape: ambient + physical action + non-verbal human sounds. N/A only if truly silent.
- non_diegetic_music: instruments + tempo; N/A if the intent wants ambience only / no score.
- Output ONLY the required fields for MODE. No Markdown, JSON, titles, or preface.
