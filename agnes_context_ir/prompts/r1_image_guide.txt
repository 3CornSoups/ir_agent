## Output format (exact section headers)

[USER CONSTRAINTS]
Locked constraints from the short intent (not guessed from the image):
- Duration (clamp 4–15)
- Forbidden items / style / camera intent
- On-screen text the user required
- Must-appear elements compatible with the attached frame(s)

[CAST]
Follow the CAST planning skill (or `dialogue=forbidden`).

[IMAGE DESCRIPTION]
For each attached image, factual English notes (visible text stays original):
- Layout: single scene | 2x2 grid | 3x3 grid | strip | other
- Subjects: who/what, costume colors, pose, left/right, near/far
- Scene, props, lighting, composition, camera angle
- For grids: scan every cell left-to-right, top-to-bottom

Mode anchors:
- I2VA: Picture 1 = FIRST frame at 0.00s / [Shot 1]
- FL2VA: Picture 1 = first @ 0.00s; Picture 2 = last @ duration
- L2VA: Picture 1 = LAST frame (landing), not the opening

[SHOT PLAN]
Follow the SHOT PLAN skill. FL2VA prefers a single shot unless the user requires more.

[DEVELOPMENT GUIDANCE]
English explanation of how the clip unfolds:
- I2VA: forward from the first frame without contradicting it
- FL2VA: continuous motion path connecting first → last (not two static descriptions)
- L2VA: plausible preceding state converging to the last frame

Do not invent assets not in the image. Do not output MiniMax field names.
Do not mention aspect ratio or resolution.
