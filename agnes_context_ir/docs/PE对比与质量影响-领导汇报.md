# 提示词增强方案对比与质量影响评估

**对比对象**：产线原版 PE（`SGLang-H3-base/pe`）→ 精简版 ContextIR（`agnes_context_ir`）  
**读者**：业务 / 产线决策  
**结论先行**：精简版用 **固定 2～3 轮编排** 替换原版的「感知 + 契约 + 双路由 + 扩写 + 格式化 + 校验」长链路；**时延与成本显著下降，输出更稳、更克制**；代价是 **题材风格 / 镜头机制的自动增强变弱**，以及 **结构化硬校验能力变浅**。接口对外兼容，可平滑切换。

---

## 1. 要解决什么问题

原版 PE 能力很全：风格 Skill、T8 镜头机制、意图契约、台词硬锁定、规则校验……但链路长、模型调用多，产线侧常见痛点是：

- **慢**：一次增强往往要串/并多轮大模型；
- **飘**：风格或镜头机制路由偶发「加戏」（炫技运镜、风格过载）；
- **难控**：中间阶段多，问题难归因。

精简版目标：**保接口、砍冗余、对齐「先理解再格式化」的短编排**，把质量策略收敛到「保真 + 克制运镜 + 对白政策」三条线上。

---

## 2. 架构对比（一眼看懂）

### 原版 PE（能力厚、链路长）

```text
用户短意图 (+ 图/视频/音频)
        │
        ├─[有图/多参考]→ 感知库存 ──(宫格不全可再扫一次)─┐
        │                                                │
        ▼                                                ▼
   意图契约（抽台词/禁项/风格…，可含多步 LLM）
        │
        ├─ 风格 Skill 路由（可 LLM 打分）  ─┐
        └─ T8 镜头机制路由（可 LLM）       ─┴→ 写法块注入
        │
        ▼
   电影级扩写 expand
        │
        ▼
   注入官方指南 + Skill 叠加 → 格式化 format
        │
        ▼
   规则校验 / 可选 LLM 修复 → 最终 prompt
```

典型一次增强的模型调用量级（默认 hybrid 路由、不开语义回验）：

| 模式 | 大约几次模型调用 | 说明 |
|------|------------------|------|
| 纯文 t2va | **约 5～7** | 契约相关 + 双路由 + 扩写 + 格式化 |
| 关键帧 i2va 等 | **约 6～8** | 再加感知（宫格不全再 +1） |
| 多参考 r2va | **约 6～8+** | 同上 |

> 注：原版里「细化 elaborate」在实现上已与扩写合并（同稿复制），文档上的五阶段实际有效是「感知 / 路由 / 扩写 / 格式化 / 校验」。

### 精简版（轮次固定、职责清晰）

```text
用户短意图 (+ 图/视频/音频)
        │
        ▼
┌───────────────────────────────────────┐
│ 按模式固定 2 或 3 轮                   │
│                                       │
│  t2va:     抽约束&润色 → 写成 H3 三字段│
│  关键帧:   看图+引导   → 写成 H3(+对齐句)│
│  r2va:     感知融合 → 情节 → 六段式    │
└───────────────────────────────────────┘
        │
        ▼
   本地清洗（对齐句 / 去画幅泄漏 / 去杂前缀）
        │
        ▼
   最终 prompt（直接可投片）
```

| 模式 | 模型调用 | 职责分工 |
|------|----------|----------|
| t2va | **固定 2** | 规划（约束+散文）→ 格式化 |
| 关键帧三模式 | **固定 2** | 看图引导 → 格式化 |
| r2va | **固定 3** | 感知融合 → 情节 → 六段格式化 |

**调用量大约降到原版的 1/3～1/2**，且上界可控（不再因宫格补扫、路由 LLM 而抖动）。

## 3. 核心逻辑差异（伪代码）

### 原版：厚栈

```text
function enhance_原版(mode, intent, media):
    inventory = null
    if 需要看图或参考:
        inventory = 感知(media)
        if 宫格扫不全: inventory = 再扫一次()

    contract = LLM抽取意图契约(intent, inventory)   # 台词/禁项/风格等
    style    = 路由风格Skill(intent, inventory)     # 可 LLM 打分
    mech     = 路由T8机制(intent, inventory)        # 可 LLM
    scene    = 扩写(intent, inventory, contract, style, mech)
    prompt   = 格式化(scene, 官方指南, skill叠加说明)
    prompt   = 规则校验与可选修复(prompt, contract)
    return prompt
```

### 精简版：短编排

```text
function enhance_精简(mode, intent, media):
    if mode == t2va:
        r1 = 抽约束 + 润色场景          # 规划轮可补 1～2 句情景对白
        r2 = 序列化为 H3 三字段         # 格式轮禁止新编对白/剧情
    else if mode in 关键帧:
        r1 = 看关键帧 + 展开/衔接/落幅引导
        r2 = 序列化 + 对齐句
    else:  # r2va
        r1 = 资产清单 + 主体 + 与意图融合
        r2 = 完整场景笔记（分镜/出场）
        r3 = 六段式 H3

    return 本地清洗(r_final)            # 无 LLM 校验轮
```

**同一原则，两边都认**：用户原意优先于写作指南示例。  
**执行方式不同**：原版靠「契约对象 + 锁定台词块 + 规则引擎」硬约束；精简版靠「上游分段产出 + 格式轮保真规则」软约束，并把对白/运镜政策写进提示词本身。

## 4. 做了哪些优化（业务语言）

| 维度 | 原版 | 精简版优化点 |
|------|------|----------------|
| **时延 / 成本** | 多阶段、多路由，调用次数高且不稳定 | 固定 2～3 轮，成本可预期 |
| **可控性** | Skill / T8 自动注入，偶发「加戏」 | 默认关闭自动风格/机制；运镜默认克制 |
| **对白策略** | 强锁定已有台词；缺台词时较少主动补全 | 禁言必无对白；对话场景缺台词时规划轮补 1～2 句；格式轮禁止发明 |
| **运镜策略** | 可能被 T8 / 电影级扩写推向炫技 | 未指定则静止或轻缓推；用户指定原样保留 |
| **结构稳定性** | 阶段多，误差可层层放大 | 轮次少，归因清晰（看第几轮稿即可） |
| **接口** | 产线已接 | **签名兼容**（风格/机制参数仍接收，运行时忽略） |
| **终检** | 规则硬修 + 可选 LLM 回验 | 仅本地清洗，去掉「改写式」LLM 校验 |

一句话：**从「全能增强器」收敛为「保真格式化器」**——少发明、少加戏、快交付。

## 5. 质量影响：逻辑推演（按场景）

以下为**机制推演**，非离线评测分数；便于决策时预期「什么变好、什么变弱」。

### 5.1 预期变好或更稳

1. **禁言 / 克制镜头类意图**  
   用户写「不要说话」「无对白」「别乱切」时，精简版政策更直白，减少原版因 T8/电影扩写带来的**多余对白或花哨运镜**。

2. **对话场景但没写台词**  
   规划轮可补 1～2 句情景对白，成片更不易「嘴动无声」；原版更偏「没写就不造」，音画完整感可能弱一点。

3. **时延与一致性**  
   调用少 → 超时少、排队少；少一层路由 → **同输入重复跑，风格漂移更小**。

4. **归因与运维**  
   出问题看「第 1 轮约束是否丢了 / 第 2 轮是否乱格式」即可，比排查「是 Skill 打分还是 T8 叠加」更快。

### 5.2 预期变弱或需接受的风险

1. **强题材 / 品牌片感**  
   原版命中风格 Skill（如品牌片、手绘、定格等）时，文风与镜头套路更「像那一类片」。精简版**不再自动套 Skill**，这类片可能更「通用电影散文」，差异化弱一档。

2. **复杂创意镜头语言**  
   T8（百余种机制）关闭后，依赖模型自身常识写镜头；**不会出现机制库里的特定高光套路**，但也不易「路由错机制」导致跑偏。

3. **台词与禁项的「硬保真」**  
   原版有契约对象 + 校验规则（漏句、错语言标签、画幅残留等可确定性抓）。精简版主要靠提示词约束 + 轻量清洗；**极端漏句/结构缺字段的兜底弱于原版规则引擎**。

4. **多宫格 / 复杂参考图**  
   原版宫格不全会补扫；精简版一轮感知融合，**格子扫漏的风险略升**（对拼图分镜、九宫格角色表更敏感）。

5. **强制指定风格/机制的业务**  
   参数仍在，但精简版忽略；若产线依赖「指定某 Skill / 某 T8」出片，需另开通道或回退原版。

### 5.3 分模式影响速览

```text
                    质量重心变化（逻辑向）
  ─────────────────────────────────────────────
  t2va     │ 更快更稳；片感/机制加成 ↓；禁言&运镜更听话
  关键帧   │ 看图→格式仍在；缺宫格补扫；对齐句本地兜底
  r2va     │ 仍保留「感知→情节→格式」三步，结构最接近原版厚度
           │ 但无 Skill/T8；主体一致性更靠 R1 清单而非机制库
  ─────────────────────────────────────────────
```

## 6. 取舍关系（决策用）

```text
                 能力厚度
                    ▲
                    │   ● 原版 PE
                    │     （Skill + T8 + 契约 + 校验）
                    │
                    │              ● 精简版
                    │                （2～3 轮保真格式化）
                    │
                    └──────────────────────────▶ 速度 / 成本 / 可控性
```

| 若业务更在意… | 建议 |
|---------------|------|
| 吞吐、时延、稳定性、少「加戏」 | **精简版为主** |
| 品牌风格、特定镜头套路、强规则保真 | **原版**，或精简版 + 人工/配置指定风格通道 |
| 多参考角色一致性 | 两者都有感知；精简版 r2va 三轮仍较完整，复杂宫格可抽检 |

---

## 7. 建议结论

1. **精简版是正确的产线默认形态**：把增强从「创意导演」收成「忠实编剧 + 格式编辑」，匹配大多数短意图投片。  
2. **质量上不是全面碾压，而是剖面迁移**：保真与克制 ↑，风格化与机制创意 ↓，结构硬校验 ↓。  
3. **对外接口已兼容**，可按流量灰度；对强依赖 Skill/T8 的少数场景保留原版或补「显式风格包」即可。  
4. 若需用数据验证本文逻辑推演，建议抽 **禁言片 / 对话缺台词 / 品牌风格片 / 九宫格参考** 四类各数十条，对比成片观感与增强耗时即可一锤定音。
