# 全参考模式改写输出格式指南

本指南说明全参考模式下改写输出的组织方式和写法。

以英文撰写全部六个改写部分。仅在 <d> 内的对白和歌词，以及场景中可见的文字中保留原始语言。

**描述详细程度：** 使 detailed_description 尽可能详细和明确。对于每个镜头，清楚确立当前构图、主体外观和位置、环境和光照、动作和状态变化、摄影机运动、当前声音，以及引用内容实际出现或生效的位置。避免将描述简化为情节概述或参考关系列表。

> 镜头、摄影机运动、说话人、对白和普通声音的基本格式与视频提示撰写指南（T2VA / I2VA / FL2VA / L2VA）共用。本指南聚焦于全参考模式特有的参考标签、分析部分和格式差异。

## 1. 整体结构

完整的改写输出由以下六个部分按顺序组成：

| 部分 | 用途 |
| --- | --- |
| subject_definitions | 定义引用内容及其参考标签 |
| summary | 总结任务类型、目标视频和主要参考关系 |
| retention_analysis | 描述引用内容如何被保留、转移或复用 |
| detailed_description | 按播放顺序描述视觉、动作、镜头、声音和对白 |
| overall_soundscape | 概括环境音和物理声音 |
| non_diegetic_music | 描述仅观众可听见的背景音乐 |

## 2. 参考标签与定义（subject_definitions）

全参考改写使用四类标签来标识引用内容的来源和作用：

| 标签 | 含义 |
| --- | --- |
| <Subject N> | 从参考素材中抽象出的、可在目标视频中复用或修改的可见内容 |
| <Picture N> | 用作具体目标帧或镜头规划锚点的参考图像 |
| <Video N> | 提供剪辑来源、续接起点或整片时间结构的参考视频 |
| <Audio N> | 被复制或引用的音频信号 |

> 一旦为某内容分配了参考标签，该标签在 subject_definitions、summary、retention_analysis、detailed_description 以及音频部分中保持相同含义。

subject_definitions 定义每项后续需要单独追踪的引用内容，例如人物、环境、源视频的结构或音轨。为每一项单独成行，说明其标签所指内容、参考角色以及需要跟踪的主要特征；当来源需要明确时，注明对应的源素材。如果 <Picture N> 或 <Video N> 仅用于指明另一引用项的来源，且后续不会单独分析或使用，则在该项定义中引用它，而不另加单独行。retention_analysis 记录每个引用项出现的位置，以及它是完全保留、部分保留、转移还是复用。

### 2.1 <Subject N>

<Subject N> 用于可复用的可见内容，包括：

- 人物、动物或物体
- 场景、背景或环境
- 服装、道具、界面或视觉效果
- 风格、动作、表情或姿势

它表示一个将在目标视频中实际使用的内容单元，而非源文件本身。一个主体可由多个参考素材定义，一个参考素材也可提供多个主体。

<Subject 1> 是 <Picture 1> 中的年轻女性，长发深色，身穿蓝色开衫，戴一条细银项链。

当同一主体来自多个素材时，合并来源并说明每个素材提供的内容：

<Subject 1> 是那位女性，其外貌来自 <Picture 1>，行走动作来自 <Video 1>。

### 2.2 <Picture N>

当参考图像本身充当镜头的首帧、关键帧、末帧、编辑后的关键帧或构图锚点时，使用独立的 <Picture N>：

<Picture 2> 是 [Shot 1] 的首帧，显示一位女性坐在咖啡馆窗边。

如果图像仅用于定义角色、场景、服装或风格，则不要创建独立的图片条目。改为在对应的 <Subject N> 定义中引用图像来源。

当图像作为分镜或镜头规划参考时，说明它对应哪些镜头以及提供何种规划信息：

<Picture 3> 是 [Shot 1] 和 [Shot 2] 的分镜参考，定义了视点、主体放置和镜头顺序。

### 2.3 <Video N>

<Video N> 保留用于整片关系，例如：

- 编辑原始视频
- 从原始视频结尾续接
- 参考原始视频的摄影机运动、剪辑、节奏或时间结构

<Video 1> 是目标视频编辑的源视频。

如果来自参考视频的人物、物体、场景、动作或效果作为可见内容被复用，仍属于 <Subject N>。<Video N> 标识素材或结构来源，不替代主体标签。

### 2.4 <Audio N>

<Audio N> 表示独立的音频素材，或来自参考视频的已启用同步音轨。常见用途包括：

- 复制全部或部分音频信号
- 参考背景音乐风格
- 参考说话人的音色和表达方式
- 使用原始音频中的对白、歌词或音效
- 参考节拍、节奏或音频连续性

当 <Audio N> 明确对应于目标说话人时，在定义中复用该说话人的全局 ID：当说话人映射到已定义的主体时，写为 <Subject N> (Sx)；否则使用稳定的声音描述后加 (Sx)。该 ID 来自目标视频的全局说话人顺序，不在音频定义中独立分配或重新编号。参见第 5.4 节的说话人编号规则：

<Audio 1> 是 <Subject 1>（S1）的音色参考。

当一个音频素材承担多种角色时，用一句自然的句子描述这些角色，而不额外创建子部分。

### 2.5 同一参考视频的视觉与音轨

<Video N> 和 <Audio N> 独立编号。每个索引仅表示该标签在自己类别中的顺序，不表示两个类别之间的配对。因此同一参考视频可能对应 <Video 1> 和 <Audio 2>；不同索引并不妨碍它们来自同一源素材。

普通参考视频不会仅仅因为文件包含声音而自动创建 <Audio N>。

<Audio N> 定义主要说明音频的角色，不必指明其来自哪个 <Video N>。仅在需要消除来源歧义时说明共用来源，例如：

<Video 1> 是目标视频编辑的源视频。
<Audio 2> 是 <Video 1> 的同步音轨，并在目标视频中复用。

## 3. summary

本部分用一段简短的英文段落总结目标视频及其参考关系。以方括号任务类型前缀开头：

[reference generation] ...
[video editing + reference generation + audio reuse] ...

根据每个参考素材在目标视频中的实际作用选择任务类型：

| 任务类型 | 使用时机 |
| --- | --- |
| keyframe completion | 图像充当目标视频的首帧、关键帧、末帧、编辑后的关键帧或其他具体帧锚点 |
| reference generation | 图像、视频或音频素材为角色、场景、风格、动作、摄影机运动、分镜等提供生成指导，但不作为具体帧，也不作为被编辑或续接的源视频 |
| video editing | 直接修改现有源视频；编辑图像或在静态关键帧之间生成内容不属于此类型 |
| video continuation | 新内容从现有源视频继续、延伸、接续或过渡 |
| audio reuse | 全部或部分复用相同的音频信号 |
| audio reference | 不直接复制音频信号，仅参考其音乐风格、音色、对白或歌词内容、音效质感、节拍或连续性 |

当任务满足多种关系时，用 + 组合任务类型，且不重复类型。例如，从源视频续接同时使用图像作为末帧，写为 [video continuation + keyframe completion]。编辑源视频同时保留其原始音频，可写为 [video editing + audio reuse]。

仅仅存在视频或音频并不会自动产生对应的任务类型。如果参考视频仅提供摄影机运动、剪辑或节奏，通常属于 reference generation。仅当该视频被直接编辑或续接时，才使用 video editing 或 video continuation。

编辑源视频时，如果其原始音频仍可听见，则同时使用 audio reuse。续接源视频但不直接复制音频信号时，若新音频仅延续原音轨的可听特征，则使用 audio reference。

摘要使用先前定义的 <Subject N>、<Picture N>、<Video N> 和 <Audio N> 标签来描述主要主体、镜头流程和参考素材的作用。不要在本部分引入新的参考标签。

对于视频编辑任务，在任务类型前缀之后以如下内容开始摘要：

The target video is an edited version of <Video 1>.

## 4. retention_analysis

本部分描述每项引用内容在目标视频中如何被保留、转移、复制或参考。为每个参考标签使用一行，并保持 subject_definitions 中确立的含义。

### 4.1 可见内容

<Subject N>、<Picture N> 和 <Video N> 使用以下关系标记。这些标记是输出格式中固定的英文值：

| 关系标记 | 含义 |
| --- | --- |
| fully_preserved | 引用内容的定义角色被完全保留 |
| partially_preserved | 引用内容仍被使用，但某些定义特征被改变或仅部分保留 |
| attribute_transfer | 引用特征被转移到另一个可识别的目标主体 |
| weak_reference | 仅保留风格、类别、构图或氛围上的宽泛相似性 |

主体条目：

<Subject 1>（出现在 [Shot 1]、[Shot 3]）：fully_preserved - ...

图片条目：

<Picture 2>（[Shot 1] 首帧）：fully_preserved - ...

视频结构条目：

<Video 1>（剪辑和节奏结构）：weak_reference - ...

### 4.2 音频

<Audio N> 使用以下关系标记：

| 关系标记 | 含义 |
| --- | --- |
| fully_copy | 完整源音频作为目标视频的完整最终音轨 |
| partially_copy | 仅复制部分时间线或选定音频层，或在复制后添加、移除或替换其他声音 |
| reference | 不直接复制信号，仅参考音色、节奏、音乐风格、对白内容或声音质感 |
| weak_reference | 仅保留类别或氛围上的宽泛相似性 |

<Audio 1>：fully_copy - <Audio 1> 以 1:1 方式复用为目标视频的完整最终音轨。

<Audio 2>：reference - 目标说话人遵循 <Audio 2> 的音色和沉稳的传达方式，但不复制原始信号。

每个关系标记的选择应仅基于该标签在 subject_definitions 中已定义的参考角色。不要将目标视频中新添加的动作、背景或情节事件视为参考保真度的损失。

## 5. detailed_description

这是全参考改写的主体部分。按目标视频播放顺序，逐镜头描述视觉、动作、声音和对白，并在适用处插入参考标签。

### 5.1 基本格式

基本格式遵循视频提示撰写指南（T2VA / I2VA / FL2VA / L2VA）：

- 主体用英文撰写。对白、歌词和可见文字保留原始语言。
- [Shot 1] 标记开场镜头，不带时间戳。后续镜头使用 [Shot N] At MM:SS.mmm, ... 标记剪辑时间。
- 在当前镜头内用自然英文撰写摄影机运动，包括运动类型、幅度和速度（如需表达）。
- 为发声源分配稳定的 (S1)、(S2) 及后续 ID。对白和歌词写为 <d>[语言] ...</d>。
- 对跨越剪辑的对白、视频结束导致的语音截断以及跨镜头的连续音频，使用 <scenetrans>、<cutoff> 及相应的连续性描述。

有关完整规则和示例，包括摄影机词汇、群体对话、画外音、跨剪辑对白和可见文字，请参见视频提示撰写指南（T2VA / I2VA / FL2VA / L2VA）。

### 5.2 全参考模式差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主要字段 | integrated_multimodal_description | detailed_description |
| 风格开头 | 写在 [Shot 1] 之后 | 在 [Shot 1] 之前用一两个英文句子确立 |
| 参考信息 | 不使用全参考标签 | 在首次出现及其作用适用处插入 <Subject N>、<Picture N>、<Video N> 和 <Audio N> |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜头或音频阶段引用 <Audio N>，并说明信号是复制还是参考 |

开头示例：

The target video is in a cinematic, literary music-video style with soft lighting and a slightly desaturated color palette.
[Shot 1] The scene opens in a crowded urban street...
[Shot 2] At 00:09.000, the shot cuts to an extreme close-up...

对于生成任务，detailed_description 通常为 350-500 英文单词。对白密集的内容优先确保完整覆盖口语时间线，而非机械达到字数。视频编辑描述随源视频的复杂度而定，不必遵循生成任务的范围。单一镜头并不自动意味着更短描述；应根据信息量在多个镜头间分配细节。

### 5.3 在镜头中使用参考标签

当重要 <Subject N> 首次清晰出现时，在镜头实际可见范围内描述其引用特征、画面位置和当前动作。后续镜头中继续使用同一标签，不重新定义标签含义。

对具体帧锚点使用自然措辞：

the shot begins from <Picture 1>
the shot's keyframe corresponds to <Picture 2>
the shot ends on <Picture 3>

当编辑或续接原始视频时，在其源状态、结构或续接关系适用的地方自然引用 <Video N>。在音频关系活跃的镜头或语义阶段引用 <Audio N>。

### 5.4 说话人、音频来源和对白

基本说话人 ID 和 <d> 格式遵循 T2VA。当引用主体实际发声时，同时保留视觉参考标签和说话人 ID：

<Subject 2>（S1）转向女性并说：<d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>

<Subject N> 标识引用主体，而 (Sx) 标识实际说话人。当主体发声时，写为 <Subject N> (Sx)。如果同一主体在画外发声，保留相同形式并标注为 off-screen。当说话人不对应已定义主体时，使用稳定的声音描述后加 (Sx)。

当语言内容仅为直接复用的 BGM 或完整配乐中的提示，且没有人物、角色、旁白或其他独立发声源实际发出时，使用 <Audio N> 作为可听来源，不额外发明 (Sx)。如果有具体人物、角色、旁白或其他独立发声源发出声音，则为该来源分配并复用 (Sx)：

When <Audio 1> reaches the phrase <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d>, <Subject 1> performs the corresponding hand gesture without becoming a separate speaker source.

当参考音频中的对白、旁白或歌词被直接复用，或输入提示明确要求重新表演时，在 <d> 内保留确切的源词和原始语言。对于无法听清的部分写 [unclear]，而非猜测或转述。将标点规范为表达句子所需的基本书面标记，如 ,、.、? 和 !；移除重复的波浪号、表情符号、项目符号以及重复或装饰性标点。完整的陈述句、疑问句和感叹句在 </d> 前分别以 .、? 或 ! 结尾。

当仅参考音色、节奏、情感或表达方式时，不要将参考音频中的原始对白带入目标视频。

按目标视频中实际发声事件的顺序一次性分配 (Sx)。在 detailed_description 中的每个实际发声事件处复用对应的 ID；在 subject_definitions 中绑定到目标说话人的 <Audio N> 定义也复用相同的 (Sx)，但绝不在其中独立分配新 ID。不要在 retention_analysis 中写 (Sx)。仅存在于直接复用的 BGM 或完整配乐中的语言提示使用 <Audio N>；由具体人物、角色、旁白或其他独立发声源实际发出的声音使用 (Sx)。

## 6. overall_soundscape 和 non_diegetic_music

这两个声音类别的定义遵循视频提示撰写指南（T2VA / I2VA / FL2VA / L2VA）。

overall_soundscape 概括全片的环境音和物理声音。对白、歌唱及与特定镜头同步的声音事件保留在 detailed_description 中：

overall_soundscape: Quiet indoor room tone and a low ventilation hum continue throughout the video.

non_diegetic_music 描述角色听不见、仅观众可听见的背景音乐。当存在音乐时，说明其乐器编制、速度和动态发展：

non_diegetic_music: A restrained solo-piano score at a slow tempo, with sustained low cello underneath and no swell.

当使用参考音频时，仅在与可听层次匹配的部分说明其复制或参考关系：环境音和音效属于 overall_soundscape，而仅观众可听的配乐属于 non_diegetic_music。如果同一音频提供两类内容，则在每个部分描述对应的关系：

overall_soundscape: The copied ambience layer from <Audio 1> continues throughout the target video.
non_diegetic_music: <Audio 2> is directly reused as the complete audience-only score.

完整的对白和歌词仅在 detailed_description 的 <d> 中撰写；不要在这两个部分重复它们。

## 7. 完整示例

subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡馆环境，包含裸露砖墙、橙色簇绒沙发配图案抱枕、霓虹灯牌和木质咖啡桌。
<Subject 2> 是 <Picture 2>、<Picture 3> 和 <Picture 4> 中的蓬松白色萨摩耶犬，有厚密白色毛发、尖耳、黑鼻和卷曲尾巴。
<Subject 3> 是 <Video 1> 中的年轻金发女性，长发金色，穿浅粉色纽扣衬衫，袖子卷起。
<Subject 4> 是 <Video 2> 中的年轻男性，深色短卷发，穿带抽绳的深灰色连帽衫。
<Audio 1> 是 <Subject 3>（S1）的音色参考，包含英语口语人声层。

summary:
[reference generation + audio reference] 目标视频显示 <Subject 3> 在 <Subject 1> 中吃饼干。<Subject 4> 带着 <Subject 2> 进入，萨摩耶向饼干扑去。三段镜头交换使用 <Audio 1> 作为 <Subject 3> 的音色参考，并以罐头笑声收尾。

retention_analysis:
<Subject 1>（出现在 [Shot 1]、[Shot 2]、[Shot 3]）：fully_preserved - 裸露砖墙、橙色簇绒沙发、图案抱枕、霓虹灯牌和木质咖啡桌均保留。
<Subject 2>（出现在 [Shot 1]、[Shot 2]）：fully_preserved - 萨摩耶的厚密白色毛发、尖耳、黑鼻和卷曲尾巴均保留。
<Subject 3>（出现在 [Shot 1]、[Shot 2]、[Shot 3]）：fully_preserved - 金发女性的身份、长发和浅粉色衬衫均保留。
<Subject 4>（出现在 [Shot 1]、[Shot 2]）：fully_preserved - 年轻男性的深色短卷发和深灰色连帽衫均保留。
<Audio 1>：reference - 其音色指导 <Subject 3> 的对白表达，但不复制原始信号。
