# 视频提示词编写指南 (T2VA / I2VA / FL2VA / L2VA)

## 1. 任务概述

- **T2VA**：根据文本构建完整视听时间轴。
- **I2VA**：T2VA 主体 + 首帧指令 + 从首帧向前发展的视觉路径。
- **FL2VA**：T2VA 主体 + 首尾帧指令 + 从首帧到尾帧的连续路径。
- **L2VA**：T2VA 主体 + 尾帧指令 + 从合理的前置状态收敛至尾帧的路径。

## 2. 最终提示词结构

### 2.1 第一部分为指令

**T2VA** 不包含图像对齐指令，直接以三个核心字段开始。

**I2VA** 始终使用：

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

**FL2VA** 始终使用：

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

**L2VA** 始终使用：

```text
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

其中，`N` 是实际最终镜头的索引，`S.SS` 是格式化为精确两位小数的有效视频时长。该指令必须作为最终提示词的第一行，随后空一行，再接核心字段。 ### 2.2 第二部分包含三个核心字段

```text
integrated_multimodal_description: [镜头 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

- **integrated_multimodal_description**：沿时间轴描述视觉画面、动作、镜头、说话者、对话、演唱以及“叙事内音响”（diegetic audio，即源自画面内世界的声响）。
- **overall_soundscape**：概括整段视频中的环境音、肢体动作声响以及非语言类的人声。
- **non_diegetic_music**：描述背景音乐，即角色无法听到、仅观众能听到的音乐。


## 3. 如何将关键帧融入多模态描述中

### 3.1 I2VA：从图像出发并向前发展

`<Picture 1>` 是视频在 0.00 秒时的实际首帧，属于 `[Shot 1]`。描述应首先确立图像中的风格、主体、构图和场景基准，随后描述接下来的动作。角色的身份、服装、色彩、关键物体及空间关系应保持一致。

推荐结构：**首帧基准 → 动作开始 → 持续发展 → 结果或反应**。

### 3.2 FL2VA：描述首帧与末帧之间的演变过程

Picture 1 为起始帧，Picture 2 为结束帧。重点关注主体的移动、姿态变化、物体操作、构图演变以及场景或光影的转换。

FL2VA 通常适用于单镜头场景，以便模型能从首帧到末帧进行连续插值。仅在明确指定多镜头的情况下才使用多个镜头。视频末尾的最后一个镜头 `[Shot N]` 必须对应于末帧画面。

推荐结构：**首帧状态 → 可观察的中间变化 → 差异逐渐缩小 → 末帧状态**。

### 3.3 L2VA：推断起始状态并最终落位于目标图像

`<Picture 1>` 是视频的末帧，属于最后一个镜头 `[Shot N]`；它并不直接对应于 Shot 1。需根据用户意图和末帧画面推断出合理的初始状态，然后描述角色、物体、摄像机和场景如何逐渐向该参考图像过渡。

推荐结构：**合理的初始状态 → 明确的动作与过渡路径 → 最终镜头中的逐渐收敛 → 最终落位于末帧**。


## 4. 如何撰写三个共享核心部分

### 4.1 沿时间轴构建多模态描述

`integrated_multimodal_description`（综合多模态描述）是重写后提示词的主体部分。每一个细节都应对应可见或可听的元素：视觉风格、初始构图、主体外观与位置、场景及关键道具、动作与反应、镜头切换、口语对话以及同步的场景内音效（diegetic sound）。

在 `[Shot 1]`（镜头 1）的开头，说明整体风格和初始构图。常见风格包括 `Cinematic`（电影感）、`live-action`（实拍）、`2D-animated`（二维动画）、`3D CG`（三维 CG）、`claymation`（黏土动画）、`watercolor`（水彩）和 `vintage film`（复古胶片）。对于关键帧任务，风格应源自参考图像；对于 T2VA（文本生成视频/动画）任务，则根据用户文本进行选择。

```text
[Shot 1] Live-action, cinematic, a medium-wide shot frames...
```

### 4.2 镜头与剪辑

第一个镜头无需标注时间戳。后续镜头应使用连续编号，并以严格递增的剪辑时间点作为开头（该时间点需在视频总时长范围内）：

```text
[Shot 2] At 00:03.500, the camera cuts to...
```

对于常规剪辑，可使用 `the camera cuts to`、`the shot cuts to`、`the shot transitions to`、`the shot changes to` 或 `the shot switches to`。若用户明确要求，也可使用 `cross-dissolve`（叠化）、`fade`（淡入淡出）或 `wipe`（划像）。剪辑应引入关于主体、空间、状态、视角或时间的新信息。如果仅需改变距离或微调角度，建议优先使用摄像机运动。

### 4.3 摄像机运动：运动类型 + 幅度 + 速度

完整的摄像机运动描述包含三个维度：**运动类型**定义摄像机的移动方式，**幅度**定义构图变化的范围，**速度**定义变化节奏。仅在有意义时添加幅度和速度描述；中等幅度和正常速度通常可省略。

| 维度 | 可用表述 | 描述 |
|-|-|-|
| 运动类型 | `Zoom In / Zoom Out` |机身保持静止，同时焦距发生变化 |
| 运动类型 | `推入 / 拉出` | 摄像机向前 / 向后移动 |
| 运动类型 | `向左摇 / 向右摇` | 摄像机位置固定，镜头水平转动 |
| 运动类型 | `向左横移 / 向右横移` | 摄像机进行水平平移 |
| 运动类型 | `向上俯仰 / 向下俯仰` | 摄像机位置固定，镜头垂直转动 |
| 运动类型 | `升降（上）/ 升降（下）` | 整个摄像机向上 / 向下移动 |
| 运动类型 | `弧形移动` | 摄像机围绕拍摄对象呈弧形移动 |
| 运动类型 | `跟拍` | 摄像机跟随移动的拍摄对象 |
| 运动类型 | `固定镜头` | 摄像机位置和镜头均保持静止 |
| 运动类型 | `轻微晃动 / 剧烈晃动` | 摄像机轻微 / 剧烈晃动 |
| 运动类型 | `POV（主观视角）` | 拍摄对象的视角 |
| 运动类型 | `顺时针旋转 / 逆时针旋转` | 摄像机绕镜头轴线顺时针 / 逆时针旋转 |
| 幅度 | `小幅度` | 小范围变化 |
| 幅度 | `大幅度` | 大范围变化 |
| 速度 | `低速` | 缓慢移动 |
| 速度 | `高速` | 快速移动 |

摄像机运动应描述为镜头内自然的动作，而不是在句末堆砌单独的标签：

```text
摄像机低速、小幅度推向她手中折叠的信件。
摄像机高速、大幅度向右摇摄，露出敞开的门口。
当奔跑者离开画面时，摄像机保持固定镜头。
```

### 4.4 说话者、对话与演唱

说话、唱歌或发出画外人声的对象需使用固定标识符（ID），例如 `(S1)` 和 `(S2)`。当多位已编号的说话者同时说话或唱歌时，使用复合标识符，例如 `(S1,S2)`。说话者在不同镜头间保持相同的标识符；从未发声的角色无需分配说话者标识符。

当说话者首次出现时，应根据视觉和听觉语境提供足够信息以确立其固定身份，例如角色类型、年龄、性别、是否在画面内、音高、音色、语速或口音。将说话者的身份描述、标识符、动作及表达方式置于 `<d>` 标签之外。`<d>` 标签内仅包含语言标签和用户提供的实际口述内容。必须逐字逐句保留所有原始词汇和标点符号，不得进行翻译或改写。

```text
声音轻柔且带有气声的年轻女子 (S1) 说道： <d>[English] 我在下一站下车。</d>
两个孩子 (S1,S2) 齐声喊道： <d>[English] 等等我们！</d>
```

对于画外音（旁白），须使用固定短语 `says in an off-screen voiceover`（以画外音形式说道）。在每个画外音 `<d>` 标签块之后，紧接着说明相应画面内角色的嘴唇保持闭合状态：

```text
男子 (S1) 以画外音形式说道： <d>[English] 我依然记得那条路。</d> 此时他的嘴唇完全闭合。
```

当同一句对话或歌词跨越镜头剪辑点时，应在两部分的连接处使用 `<scenetrans>` 标签，并明确说明音频在剪辑点处延续。当语音因视频结束而中断时，使用 `<cutoff>` 标签。关于连续性的描述可使用诸如 `continues seamlessly across the cut`（跨越剪辑点无缝延续）、`continues uninterrupted into the next shot`（不间断地延续至下一镜头）、`carries over from the previous shot`（从上一镜头延续而来）或 `remains audible across the transition`（在转场过程中保持可听）等表述。

### 4.5 画面内文字

将画面中实际可见的横幅、标牌、标签、字幕或霓虹灯文字置于英文双引号内。请逐字保留原文及标点，无需翻译。

```text

门口上方亮着一块写着“营业中”的红色霓虹灯招牌。

```

### 4.6 整体音景

请使用 1-4 个英文句子，以一个连续的段落概括整个视频中的环境音、物理动作音和非语言人声，例如风声、雨声、交通声、脚步声、布料摩擦声、撞击声、呼吸声、笑声或喘息声。对话、歌声和视频中的配乐已包含在多模态描述中，无需在此处重复。仅当用户明确要求视频全程保持静音时，才使用 `N/A`。

```text

整体音景：雨点淅淅沥沥地敲打着咖啡馆的窗户，窗下传来低沉的室内环境音。入口处的门铃响了一声，随后是湿漉漉的脚步声和椅子轻微的摩擦声。

```

### 4.7 非叙事性音乐

请用 1-3 个英文句子描述角色听不到、只有观众才能听到的背景音乐。重点描述乐器、速度、节奏和力度变化；不要使用抽象的情绪词汇或解释乐曲的情感功能。角色能听到的歌声、乐器声、广播、电视或电话音乐都属于叙事性事件，应在多模态描述中提及。如果没有非叙事性音乐，请使用“N/A”。

```文本

非叙事性音乐：缓慢的钢琴音符稀疏而悠扬，随后加入持续的低音弦乐，音量逐渐增大，最终消失。

```


## 5. 案例

### 案例 1：T2VA

在没有参考图像的情况下，直接根据文本构建完整的时间轴。您可以添加与用户意图保持一致的场景、角色、动作和声音细节。

```text
integrated_multimodal_description: [镜头 1] 实拍，电影质感，中远景镜头捕捉了一位面包师在日出前打开街边小面包店百叶窗的画面。当这位声音沉稳、略带沙哑（S1）的中年面包师将一个新鲜面包放在木质柜台上并说道 <d>[英语] 早上第一批出炉的面包。</d> 时，摄像机缓慢且小幅度地推进。 [镜头 2] 在 00:05.000 处，画面切换至切开的面包上腾起的蒸汽特写，同时面包师的最后一句话音效延续自上一个镜头。

overall_soundscape: 安静的街道上响起木质百叶窗被推开的摩擦声，店内传来托盘轻微的碰撞声。门铃响了一声，随后是轻柔的脚步声和切面包时清脆的声响。

non_diegetic_music: 中速柔和的木吉他旋律，伴有稀疏的立式低音提琴音符，结尾处声音轻柔淡出。
```

### 案例 2：I2VA

首先编写首帧指令，然后以 <Picture 1>（来自 [镜头 1]）中的主体、构图和场景作为 [镜头 1] 的起点，描述场景的后续发展。

```text
对于目标视频，在视频开始的 0.00 秒处，完全参考 <Picture 1>（来自 [镜头 1]）。

integrated_multimodal_description: [镜头 1] 实拍，电影质感，<Picture 1> 中展示的年轻女子保持在布满雨水的火车车窗旁，其外貌、着装、座位位置及车厢布局均保持不变。当她将视线从折叠的信件移向窗外掠过的城市灯光时，摄像机缓慢且小幅度地向右平移。
```她的倒影在玻璃上移动，同时那位说话轻柔、气息明显的年轻女子（S1）说道：<d>[英语] 我下一站下车。</d> 她沿着原有的折痕将信折好。

整体音景：列车车轮发出稳定的金属节奏声，背景伴随着低沉的通风机嗡嗡声。雨点敲击着车窗，手中纸张发出轻微的沙沙声。

非叙事音乐：大提琴持续的长音，节奏缓慢，间杂着间隔疏朗的钢琴音符，音量逐渐减弱。
```

### 案例 3：FL2VA

这两张图片分别作为开头和结尾的锚点。正文不应重复描述两张静态图片，而应提供连接两者的动作轨迹。以下示例为一个时长八秒的单镜头。

```text
参考图片与目标视频的对应关系——图片 1（来自镜头 1）对应目标视频的 0.00 秒处；图片 2（来自镜头 1）对应目标视频的 8.00 秒处。

综合多模态描述：[镜头 1] 实拍，电影质感。一位被雨淋湿的骑行者处于图片 1 设定的位置和构图中，手持一把收拢的黑伞，站在一辆银色自行车旁。随着镜头缓慢、小幅度地拉远，她松开自行车把手，将伞举过肩头，向上推动伞骨滑块，直至伞面撑开。雨水从展开的伞布上滑落，她迈步走到伞下，将伞柄转至最终角度，并定格在镜头结束时由图片 2 设定的姿势、间距和构图中。

整体音景：雨水稳定地落在路面上，随后传来伞骨滑块的金属咔哒声和伞面撑开时的轻微脆响。远处有车辆驶过，自行车车架上滴落着水珠。

非叙事音乐：无
```

### 案例 4：L2VA

图片仅作为最终时刻的锚点。首先设定一个相容的初始状态，然后通过动作、物体状态和构图的变化，使画面在镜头结束时逐渐过渡到图片 1 的状态。以下示例为一个时长六秒的单镜头。

参考图片与目标视频的对应关系 —— <图片 1>（源自[镜头 1]）对应目标视频的 6.00 秒处。

综合多模态描述：[镜头 1] 实拍、电影质感。特写镜头开始时，一只完好的玻璃杯放置在深色木桌边缘附近；画面右侧出现了一只手及其衣袖，与 <图片 1> 中的特征一致。当指尖触碰杯沿时，摄像机缓慢且小幅度地推进。玻璃杯倾斜、坠落，重重地撞击地面并发出清脆的碎裂声；裂纹迅速蔓延，碎片向外滑散。在镜头末尾，移动的碎片失去动能，最终呈现出与 <图片 1> 完全一致的破碎形态、手部位置、摄像机角度、光照效果及构图。

整体声景：指尖轻敲玻璃杯，随后杯身在桌面上摩擦、坠落，并伴随清脆的碎裂声破裂。细碎的玻璃片四散飞溅，随后逐渐停止在地板上滑动。

非叙事性音乐：低沉的电子脉冲音效，节奏缓慢，在玻璃杯破碎后立即停止。
